# Chat Self-Hosted

A self-hosted, private chat application for personal use — a full-stack showcase of scalable architecture, secure authentication, and real-time messaging.

## What it is

A private messaging platform you run yourself, keeping your conversations in your own hands. Designed to demonstrate end-to-end product: from account creation to real-time communication.

## What it aims to deliver

- **Secure sign-up and sign-in** with email
- **Real-time private chat rooms**
- **Persistent message history** so nothing is lost between sessions
- **User management** (profile and display name)
- **Self-hosting** with a simple one-command local deployment

## Status

Early build — an MVP is in active development. The wider vision is a privately hosted chat experience that is fast, reliable, and easy to deploy.

## Roadmap

- MVP: secure auth, real-time messaging in private rooms, persistent history
- Beyond: richer user profiles, media sharing, and additional deployment options
